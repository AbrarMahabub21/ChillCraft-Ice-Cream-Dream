# ChillCraft Ice Cream Dream

A small React app where you build an ice cream by adding and removing scoops, and the total price updates as you go.

## What it does

- Pick from five flavours, each with its own price
- Add or remove scoops and see them stacked on the cone
- Shows the total price

There is also a plain HTML and CSS version in `chillcraft/html`.

## Stack

React (Create React App, class components) and CSS modules.

## Run it locally

```
cd chillcraft
npm install
npm start
```
